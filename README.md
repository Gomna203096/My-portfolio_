# Jonah Gomna Personal Portfolio

This static multi-page portfolio is built for COEN 554 Question One.

Technologies:
- HTML5 semantic structure
- CSS3, Flexbox/Grid and responsive media queries
- JSON data model
- JSON-LD metadata
- No JavaScript
- No CMS

Pages:
Home, About Me, Educational Background, Technical Skills, Projects,
Hobbies & Interests, CV, Contact Me.

Directory:
assets/css/style.css
assets/images/
data/data.json

Replace the initials portrait on the Home page with a professional photo when available,
and replace the contact placeholders with the preferred email and social links.
